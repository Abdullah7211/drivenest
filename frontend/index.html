DriveNest

Every Google Drive you own, in one list.

DriveNest is a web application that lets you connect multiple Google accounts and browse, search and open your Google Drive files and folders from all of them in one place. It uses read-only access to Google Drive file metadata (names, types, dates, sizes and links) and cannot read file contents or change, upload or delete anything.

  • Connect several Google accounts
  • Browse files and folders from all accounts in one list
  • Search by file name and switch between accounts
  • Disconnect any account at any time
